Figure 5: Overview of ANN algorithms — per-phase complexity

N=dataset size · d=dimensions · K=clusters · n=N/K (cluster size) · M=graph degree · ef=beam width · L=LSH tables

Algorithm Build index Query routing Search within Total query cost Insert cost Memory
Brute force O(1) — O(N·d) O(N·d) O(1) O(N·d)
LSH [3] O(N·d·L) O(L·d) O(bucket·d) O(L·d) O(L·d) O(N·L)
FAISS IVF [5] O(N·K·d) O(K·d) O(n_probe·n·d) O(K·d + np·n·d) O(d) O(N·d)
NSW [8] O(N·M·d) greedy 1-layer O(ef·M·d) O(ef·M·d) O(M·d) O(N·M)
HNSW [9] O(N·M·d·log N) greedy layers O(ef·M·d) O(ef·M·d·log N) O(M·d·log N) O(N·M)
DiskANN [11] O(N·M·d·log N) disk reads O(ef·M·d) O(ef·M·d·log N) O(M·d) O(N) disk
Clustered HNSW [ours] O(K·n·M·d·log n) O(K·d) O(T·ef·M·d·log n) O(K·d + T·ef·M·d·log n) O(d + M·d) O(N·M)
Why clustered build is faster:
HNSW: O(N·M·d·log N) — one large graph
Ours: O(K·n·M·d·log n) where N = K·n
= O(N·M·d·log(N/K))
K=1000, N=1M → log N=20, log n=10
→ ~2× faster per vector, confirmed: 1013s → 66s
Query routing overhead:
Extra cost vs HNSW: O(K·d) centroid scan
K=1000, d=128 → 128,000 extra ops/query
T=TOP_CLUSTERS controls recall/speed
T=1 → fastest, T=20 → matches baseline recall

Variables: N=1,000,000 · d=128 · K=1000 · n≈1000 · M=16 · ef=50 · T=TOP_CLUSTERS. Build: O(N·M·d·log N) for full HNSW vs O(N·M·d·log n) for clustered, where log n = log(N/K). Insert: O(d) centroid lookup + O(M·d) HNSW insert = cheaper than full HNSW O(M·d·log N). [3] Indyk 1998 · [5] Johnson 2017 · [8] Malkov 2011 · [9] Malkov 2016 · [11] Jayaram 2019

Higher right = better. Each point = one parameter configuration. QPS on log scale. Mac hardware (single thread).

Figure 6: Recall@1 vs QPS on SIFT1M (1M×128, Euclidean distance). ANN-benchmarks reference (gray) shows hnswlib on a Linux server — QPS difference is hardware, not algorithm. Our clustered approach at TOP=1 achieves 34% higher QPS than baseline HNSW at lower recall. At TOP=20 our method matches baseline recall (0.9689 vs 0.9686) while searching only 2% of vectors. FAISS IVF achieves higher QPS due to flat scan advantage at small cluster sizes (~1000 vectors). Build time: FAISS IVF=2.11s, Clustered HNSW=66s, Baseline HNSW=1013s. Dataset: SIFT-128-Euclidean [D1]. Framework: ANN-Benchmarks [C1]. [D1] Jégou et al. 2010 · [C1] Aumüller et al. 2019
