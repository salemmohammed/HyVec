1. Evolution of ANN Indexing Designs

Approximate nearest neighbor search evolved from exact linear scanning into multiple index families. Each family introduces a different way to reduce the search space: hashing, clustering, quantization, graph traversal, or hybrid partitioning.

Figure 1. Design evolution of ANN indexing families. The arrows show conceptual influence, not strict implementation inheritance. Our method combines cluster-based routing with graph-based local search.

3. Proposed Hybrid Attribute-Spatial HNSW Architecture

The proposed method is designed for filtered vector search. It first reduces the search space using attributes, then preserves vector locality using spatial clustering, and finally performs fast approximate search using local HNSW graphs.

Index constructionPartition vectors by metadata attribute. Within each attribute partition, run MiniBatch K-Means to form spatial clusters. Build one HNSW graph per final cluster.
Query processingApply the attribute filter first. Compare the query vector with centroids in the selected attribute partition. Search only the top-nprobe local HNSW graphs, then merge and rank candidates.

Important. In the proposed method, C refers only to the centroids inside the selected attribute partition, not all centroids in the database. Attribute filtering first reduces the search space, then centroid routing selects the top-T spatial clusters, and HNSW search is performed only inside those local clusters.
